# Интернет-магазин

## Описание:

Ядро для интернет-магазина — реализация классов `Product`, `Category`, а также классов-наследников `Smartphone` и `LawnGrass` с инкапсуляцией, геттерами/сеттерами, магическими методами (`__str__`, `__add__`), проверкой типов

## Установка:

Клонируйте репозиторий:
```
git clone https://github.com/Tatiana-Bakina/Module4
```

## Функции в проекте

### Модуль products
 Абстрактный класс **BaseProduct**
- Базовый класс для всех продуктов
- Определяет обязательные методы: `__str__`, `__add__`, `price` (геттер/сеттер)

Миксин **MixinProductInfo**
- При создании объекта выводит в консоль информацию о классе и параметрах
- Добавлен в цепочку наследования класса `Product`
- Пример вывода: `Smartphone('Samsung Galaxy S23 Ultra', '256GB, Серый цвет, 200MP камера', 180000.0, 5)`

Класс **Product**, который хранит информацию о товаре:
- `name` — название
- `description` — описание
- `__price` — цена (приватвный атрибут)
- `quantity` — количество на складе
При добавлении товара с нулевым количеством выводит ошибку `Товар с нулевым количеством не может быть добавлен.`

**Классы-наследники:**
**Smartphone (смартфон)**
Добавляет свойства:
- `efficiency` — производительность
- `model` — модель
- `memory` — объём встроенной памяти
- `color` — цвет

**LawnGrass (газонная трава)**
Добавляет свойства:
- `country` — страна-производитель
- `germination_period `— срок прорастания
- `color` — цвет

**Магические методы:**
- `__str__` — возвращает строку в формате: `"Название, X руб. Остаток: X шт."`
- `__add__` — складывает товары только одного типа, возвращает общую стоимость: `(цена × количество) + (цена × количество)`. При попытке сложить товары разных классов выбрасывает `TypeError`.

**Геттер и сеттер для цены:**
- При попытке установить цену ≤ 0 выводится сообщение об ошибке
- При понижении цены запрашивается подтверждение пользователя

**Класс-метод new_product():**
- Создаёт новый товар из словаря
- Проверяет наличие дубликатов по имени
- При обнаружении дубликата складывает количество и выбирает максимальную цену

### Модуль category
Используется класс Category, который хранит информацию о категории товаров:
- `name` — название категории
- `description` — описание
- `__products` — список объектов Product (приватный атрибут)

**Магические методы:**
- `__str__` — возвращает строку в формате: `"Название, количество продуктов: X шт."` (где X — суммарное количество товаров на складе)


**Методы:**
- `add_product(product)` — добавляет товар в категорию. Принимает только объекты класса Product или его наследников. При попытке добавить другой тип выбрасывает `TypeError`.
- `products` — геттер, возвращающий строковое представление всех товаров в формате:
`"Название, X руб. Остаток: X шт.\n"`
- `middle_price` - возвращает среднюю цену товаров в категории. Если товары отсутствуют, возвращает 0. 

**Атрибуты класса Category:**
- `total_categories` — общее количество категорий
- `total_products` — общее количество товаров в категории
