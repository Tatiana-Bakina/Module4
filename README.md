## Функции в проекте

### Модуль products
Используется класс Product, который хранит информацию о товаре:
- `name` — название
- `description` — описание
- `__price` — цена (приватвный атрибут)
- `quantity` — количество на складе

**Магические методы:**
- `__str__` — возвращает строку в формате: `"Название, X руб. Остаток: X шт."`
- `__add__` — складывает два товара, возвращает общую стоимость: `(цена × количество) + (цена × количество)`

**Геттер и сеттер для цены:**
- При попытке установить цену ≤ 0 выводится сообщение об ошибке
- При понижении цены запрашивается подтверждение пользователя

**Класс-метод new_product():**
- Создаёт новый товар из словаря
- Проверяет наличие дубликатов по имени
- При обнаружении дубликата складывает количество и выбирает максимальную цену

### Модуль category
Используется класс Category, который хранит информацию о категории товаров:
- `name` — название категории
- `description` — описание
- `__products` — список объектов Product (приватный атрибут)

**Магические методы:**
- `__str__` — возвращает строку в формате: `"Название, количество продуктов: X шт."` (где X — суммарное количество товаров на складе)


**Методы:**
- `add_product(product)` — добавляет товар в категорию
- `products` — геттер, возвращающий строковое представление всех товаров в формате:
"Название, X руб. Остаток: X шт.\n"

**Атрибуты класса Category:**
- `total_categories` — общее количество категорий
- `total_products` — общее количество товаров в категории


## Тестирование проекта
Проект покрыт тестами с использованием библиотеки `pytest`. Тесты находятся в директории `tests/`.

- Запуск всех тестов: `pytest tests/`
- Проверка покрытия: `pytest --cov=src --cov-report=term`
- Генерация HTML‑отчёта: `poetry run pytest --cov=src --cov-report=html`
